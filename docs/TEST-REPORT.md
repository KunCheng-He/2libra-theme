## 三、发现的 Bug（按优先级）

### 🔴 BUG-1（高）子节点页伪装被站点 React 静默清除，引擎无自愈
- **现象**：直开/刷新任意二级节点页（`/node/{parent}/{child}`，如 `/node/product/feature-request`、`/node/daily-life/personal-life`，4/4 复现），伪装 UI 在 ~950ms 后消失，退回原版；引擎内部状态仍是 `active`（自认为正常），不再恢复
- **根因**（CDP trace 实锤）：这些页面站点自身存在 React 水合错误（console "Minified React error #418"）。Next.js/React 的水合恢复路径（chunk `545eeaab` 内 `clearContainer` 类逻辑）会**清空 `<html>` 下的"外来"子节点**——trace 捕获到 `html.removeChild(host)`，调用栈直指站点 chunk。我们的宿主 div 挂在 `documentElement` 上，成为清除对象；`data-2lt-on` 属性随后也丢失。首页/父节点页/帖子页无水合错误，host 存活
- **影响**：伪装在最常见的浏览路径上不可靠地丢失
- **修复建议**：引擎对 host 做存活监护（MutationObserver 监听 `documentElement` childList），发现 host 被移除且 `state==="active"` 时：重建 host + 重新挂载主题（ShadowRoot 随元素销毁，必须重建）；或改挂载点并配合监护
- **备注**：D3（子节点过滤）功能本身代码正确，被本 bug 阻断无法端到端验证

### 🟠 BUG-2（中）特殊 `/post/*` 聚合路由被误判为帖子 → 空白卡死不回退
- **现象**：访问 `/post/hot/today`（站点的"今日热议"聚合页，标题"今日热议 - 24小时最热门话题"），聊天区永久停留在空骨架，无内容无输入框，**不会回退原版**
- **根因**：`matchRoute` 正则把 `/post/hot/today` 当作 `{parent:"hot", postId:"today"}`；`/api/posts/today` 返回 `c:0` 但 `d:null`（非帖子），`getPost` 抛"帖子不存在"后仅 toast，UI 停留在骨架
- **修复建议**：`getPost` 拿到 `d:null` 时调用 `escapeHatch()` 回退原版（符合 PLAN"未映射路由自动回退"原则）；或路由解析排除已知特殊段（`hot`/`latest` 等）
- **横向排查建议**：检查是否存在其他 `/post/{特殊段}/...` 聚合路由

### 🟠 BUG-3（中）快速连点会话存在竞态：旧响应覆盖新会话
- **现象**：快速连续点击 3 个会话后，URL 与列表选中项是最后点击的帖子（T_SnyUE=签到文案帖），但**聊天窗口渲染的是另一个帖子的内容**（macbook 帖）——三处 UI 自相矛盾
- **根因**：`loadChat` 无请求序号守卫/无中止机制，乱序返回时旧响应覆盖新状态
- **修复建议**：`loadChat` 记录自增请求 ID，渲染前校验仍是当前 `route.postId`；或用 AbortController 取消前次

### 🟡 BUG-4（低）深链直开帖子时会话列表空"暂无会话"
`handleRoute` 的 `post` 分支不加载列表；直接打开帖子 URL（新标签/分享链接/刷新）时左栏无会话。建议 post 路由 boot 时也懒加载列表

### 🟡 BUG-5（低）站点自定义表情未转译
`:cunning:`、`:smirk:`、`:snicer:` 等表情代码以原文显示（站点正文/评论大量使用）。建议补充表情代码 → 图片映射

### 🟡 BUG-6（低）装饰 toast 文案重复
聊天工具条点击 toast 为「该功能暂未开放」暂未开放 —— 名称与模板拼接重复。建议 `onDecorate` 传功能名（表情/截图等）而非固定文案

### ℹ️ 体验观察（不计 Bug）
- 搜索触发后搜索面板重渲染会**替换 input，焦点丢失**，连续输入需重新点击
- 搜索请求 400ms 防抖正常；站点搜索 API 本身对常见词返回空（带 token 复测确认，原站搜索同样为空）——扩展行为与站点一致，非扩展问题
- 会话列表摘要固定为"xxx：回复了帖子"，样图中为消息内容预览（映射层可优化项）
